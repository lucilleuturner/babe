# Решение проблемы: из 125 страниц извлекается только 30 товаров

## Возможные причины

### 1. n8n обрабатывает файлы по одному
Если вы используете `Read Files From Directory`, n8n может обрабатывать файлы последовательно, и каждый файл даёт отдельный результат. Нужно объединить результаты.

**Решение**: Используйте `Merge` node или `Aggregate` node после Code Node, чтобы объединить все товары из всех файлов.

### 2. Ограничение на количество элементов в n8n
n8n может ограничивать количество выходных элементов в одном узле.

**Решение**: Используйте `Split In Batches` node для обработки больших объёмов данных.

### 3. Проблема с логикой извлечения блоков
Старая версия кода могла неправильно находить закрывающие теги.

**Решение**: Используйте улучшенную версию кода.

## Рекомендуемое решение

### Вариант 1: Улучшенный код (рекомендуется)

Используйте код из файла **`n8n_extract_blocks_simple_v2.js`** - он использует простую логику: извлекает блоки от одного `product-item-` до следующего.

### Вариант 2: Версия с отладкой

Используйте код из **`n8n_extract_blocks_debug.js`** - он покажет:
- Сколько всего ID найдено
- Сколько уникальных ID
- Сколько успешно извлечено
- Процент успешного извлечения

Это поможет понять, где теряются товары.

## Workflow для обработки всех файлов

```
Read Files From Directory 
  → Code (Extract Blocks) 
  → Merge/Aggregate (объединить все товары)
  → Output
```

Или:

```
Read Files From Directory 
  → Code (Extract Blocks) 
  → Split In Batches (если слишком много элементов)
  → HTML Extract
  → Output
```

## Проверка

1. **Запустите код с отладкой** (`n8n_extract_blocks_debug.js`)
2. Посмотрите на `_debug` в первом элементе:
   - `totalMatchesFound` - сколько всего найдено ID
   - `uniqueIdsFound` - сколько уникальных ID
   - `successfullyExtracted` - сколько успешно извлечено
   - `extractionRate` - процент успешного извлечения

3. Если `totalMatchesFound` большое, но `successfullyExtracted` маленькое - проблема в логике извлечения
4. Если `totalMatchesFound` маленькое - проблема в поиске ID (возможно, другой формат ID в HTML)

## Быстрое решение

Скопируйте код из **`n8n_extract_blocks_simple_v2.js`** - он самый простой и надёжный:

- Находит все ID товаров
- Извлекает блоки от одного ID до следующего
- Не использует сложную логику с закрывающими тегами
- Работает для всех товаров на странице

## Если проблема остаётся

1. Проверьте один HTML файл вручную - сколько там товаров с `id="product-item-*"`?
2. Запустите код с отладкой и посмотрите на `_debug`
3. Возможно, товары находятся не в отдельных блоках с ID, а в контейнере - тогда нужен другой подход
