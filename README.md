# Скрипт для объединения уникальных товаров

Этот скрипт обрабатывает таблицу с товарами конкурентов и объединяет дубликаты товаров, оставляя товар с наименьшей ценой в каждой группе.

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Использование

### Способ 1: С аргументами командной строки

```bash
python merge_unique_products.py input.xlsx output.xlsx
```

### Способ 2: Интерактивный режим

```bash
python merge_unique_products.py
```

Скрипт попросит ввести пути к входному и выходному файлам.

## Формат входных данных

Таблица должна содержать следующие колонки:
- ID товара
- Название товара
- Описание
- Подкатегория
- Бренд
- Линейка
- Вязкость
- Объем тары
- Тип базы
- Цена

## Логика работы

1. **Строки конкурентов** (eurosmaz.shop, atf.ru, gmformula, techaerosol.ru, 7ft, VSEINSTRUMENTI, PROMTECHSERV) остаются без изменений.

2. **Группировка товаров** выполняется по:
   - **Бренду** (без учета регистра)
   - **Линейке масла** (извлекается из названия товара, если отсутствует)
   - **Объему тары** (точное совпадение)

3. В каждой группе одинаковых товаров остается товар с **наименьшей ценой**.

4. Все остальные колонки сохраняются из выбранного товара.

## Пример

Если есть два товара:
- Бренд: "Газпромнефть", Линейка: "G-Box GL-4", Объем: "20 л", Цена: 11000
- Бренд: "газпромнефть", Линейка: "G-Box GL-4", Объем: "20 л", Цена: 10886

Они будут объединены, и в результате останется товар с ценой 10886.
